# 信息安全导论小组作业：S-DES 加解密实现

基于《信息安全导论》课程所述 S-DES（Simplified DES）标准完成的小组作业，包含 **加密实现**、**解密实现** 与 **测试文档** 三部分。核心算法以 Python 编写，加密部分提供 PyQt5 图形界面，解密部分提供命令行交互。

- **分组长度**：8-bit
- **密钥长度**：10-bit
- **覆盖功能**：S-DES 加密、S-DES 解密、暴力破解与密钥碰撞分析

## 模块说明

### 加密部分（`加密部分/`）

| 文件 | 职责 |
| ---- | ---- |
| `sdes.py` | 实现置换、密钥扩展、轮函数与整体加密流程，纯算法无界面依赖，对外暴露 `encrypt(plaintext, key)`。 |
| `main.py` | 程序入口，负责输入校验、调用 `sdes.encrypt`、展示密文与各步骤中间值。 |
| `ui_mainwindow.py` | 仅负责界面布局与控件定义，业务逻辑不在此文件。 |
| `test_brute.py` | 测试工具：关卡 4 遍历 1024 个密钥暴力破解；关卡 5 固定明文遍历全部密钥统计密钥碰撞。 |
| `start.bat` | 检测并安装 PyQt5 依赖后调用 `python main.py`，出错时暂停窗口便于查看信息。 |
| `requirements.txt` | Python 依赖清单。 |

### 解密部分（`解密部分/`）

| 文件 | 职责 |
| ---- | ---- |
| `sdes_decrypt.py` | S-DES 解密核心算法。解密与加密结构相同，唯一区别是 **子密钥使用顺序相反**（加密 k1→k2，解密 k2→k1），公式：`P = IP⁻¹( f_k1( SW( f_k2( IP(C) ) ) ) )`。含加解密闭环自测。 |
| `cli_main.py` | 命令行交互菜单，支持加密、解密与退出，并打印各步骤中间值。 |

### 文档与测试部分（`文档与测试部分/`）

包含测试方案、测试用例文档、测试报告三份 Word 文档，以及 TC01–TC04 四张测试截图附件，构成完整的测试证据链。

## 运行方法

### 加密（图形界面，`加密部分/`）

方式一（Windows 推荐）：双击 `start.bat`，脚本会自动检查并安装 PyQt5 依赖。

方式二（命令行）：

```bash
python main.py
```

操作步骤：

1. 在“明文”输入框输入 8-bit 二进制数（如 `01010100`）。
2. 在“密钥”输入框输入 10-bit 二进制数（如 `1010000010`）。
3. 点击“加密”按钮。
4. 界面显示 8-bit 密文及各步骤中间结果。

### 解密（命令行，`解密部分/`）

```bash
python cli_main.py
```

按菜单提示选择加密 / 解密，并依次输入 8-bit 密文与 10-bit 密钥。

### 测试工具（`加密部分/`）

```bash
python test_brute.py
```

按提示选择：`1` 暴力破解，`2` 密钥碰撞分析。
